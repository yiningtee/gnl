# Description
`get_next_line` is a custom C project I created as part of the 42 curriculum. The primary objective of this project is to engineer a reliable C function capable of sequentially parsing and extracting data from a file descriptor line by line until the end of the input stream is reached.

# Instructions
1. For installation : Clone the repository to your local device
2. For compiling: get_next_line.c get_next_line_utils.c
3. For running: Simply type out ./a.out
